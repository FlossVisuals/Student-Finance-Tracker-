# Student-Finance-Tracker- 💰

# #  About the project 
Student Finance Tracker is a simple website designed to helps students manage their personl finances by keeping track of income and expenses.

The project is a part of mg learning journey in Front-End Web Development as a Banking and Finance student at Kogi State University Kabba, Kogi State.

# # Project Aim
The aim of this project is to create simple and user-friendly website that introduces student monitor income, expenses, and remaining balance.

# # Features 
- Financial summary showing total income, total expenses, and balance.
- Transaction form for entering financial records.
- Transaction type selection for income and expenses.
- Recent transaction displayed on the webpage.
- Automatic calculation of income, expenses, and balance.
- Form validation to prevent invalid entries.
- Successs message after submitting a transaction.
- Responsive design for mobile phones and computers.

# # Technologies Used 
- HTML: Used to structure the website. 
- CSS: Used to style the website and make it responsive
-  Javascript: Used to handle form submission, validate user input, calculate income and expenses, update the balance, and display transactions.

# # Project Limitations
- Transaction records are not saved permanently.
- Refreshing the page resets the financial summary and transaction history.
- The website does not yet have a database or backend system.
