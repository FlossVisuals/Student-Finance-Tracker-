# Student-Finance-Tracker- 💰

# #  About the project 
Student Finance Tracker is a simple website designed to helps students manage their personl finances.

The project is a part of mg learning journey in Front-End Web Development as a Banking and Finance student, currently studying in Kogi State University Kabba, Kogi State.

# # Project Aim
The aim of this project is to create simple and user-friendly website that introduces student to managing their income and expenses.

# # Features 
- Financial summary section
- Income and expense transaction form
- Transaction type selection
- Recent transaction section
- Responsive design for mobile phones and computers 
- Simple Javascript from submission message 

# # Technologies Used 
- HTMl _ For the structure of the website 
- CSS _ For styling and reaponsive design
-  Javascript _ For displaying a message when the form is submitted
